日文直播实时双语字幕 · 使用说明
================================

它做什么
--------
在屏幕底部浮一条字幕：上面是中文（大字），下面是日文原文（略小）。
它只抓「电脑正在播放的声音」—— 你在浏览器、播放器里正常看直播就行，
不需要填链接、不需要 cookie、不需要登录任何账号。

第一次使用
----------
1. 安装完会自动打开一个黑色窗口下载模型（约 4GB，视网速十几分钟）。
   中途关掉没关系，下次从开始菜单点「下载模型（首次必做）」会接着下。
2. 双击桌面上的「日文直播实时字幕」。
3. 面板里确认「输出设备」是你正在放声音的那个设备（一般默认就对）。
4. 点「开始字幕」，面板会收进托盘，字幕条出现在屏幕底部。
5. 在浏览器里播放日文直播，字幕就会跟着出来。

字幕条操作
----------
  鼠标左键拖动      移动位置（会自动记住，重启也还在）
  Ctrl+Shift+H      显示 / 隐藏
  Ctrl+Shift+T      鼠标穿透（点了不挡后面的浏览器）
  Ctrl+Shift+O / I  字号变大 / 变小
  Ctrl+Shift+C      清空当前字幕
  Ctrl+Shift+R      回到默认位置（底部居中）
  Ctrl+Q            退出

托盘图标（右下角）右键：显示设置面板 / 停止字幕 / 退出。

想让中文翻译更好
----------------
默认用的是本地模型（免费、离线），能把大意翻出来，但口语句会出错。
想要明显更好的翻译，在面板里把「中文翻译」选成「大模型 API」，填上 DeepSeek 的
API Key（platform.deepseek.com 申请），地址和模型名已经默认填好
（https://api.deepseek.com · deepseek-flash），点「测试连接」确认通了再开始。
Key 会存在程序目录的 settings.json 里（明文，自己机器上用没问题）。

常见问题
--------
· 一直没有字幕
  先确认直播确实在出声（不是静音/耳机没插好）。还是不行就把程序目录里的
  livecap.log 发出来看看。

· 提示缺模型 / 一启动就报错
  开始菜单点「下载模型（首次必做）」，或在面板里点「检查 / 下载模型」。

· 电脑没有 NVIDIA 显卡
  也能用，会自动退回 CPU 识别，只是慢一些、字幕延迟大一点。
  建议在面板把「识别模型」换成 large-v3-turbo。

· 字幕有延迟
  正常在 1 秒上下。想更快：识别模型选 large-v3-turbo；
  或者下载模型后用命令行版 livecap-cli.exe --max-segment 4 试试。

· 只想看日文、不要中文
  面板「中文翻译」选「不翻译（只看日文）」。

卸载
----
开始菜单里的「卸载 日文直播实时字幕」，或在 Windows「应用和功能」里卸载。
模型文件（约 4GB）也会一起删掉。

命令行版（可选）
----------------
同目录的 livecap-cli.exe 支持更多玩法：
  livecap-cli.exe --help                      查看全部参数
  livecap-cli.exe --download-models           手动下载 / 补下模型
  livecap-cli.exe --check-models              检查模型是否齐全
  livecap-cli.exe --source file --file x.mp4  拿本地视频试效果
  livecap-cli.exe --source url --url "..." --cookies cookies.txt
                                              直接拉直播流（YouTube 需要 cookie）
